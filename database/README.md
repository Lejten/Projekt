# Baza danych

`database.sql` zawiera relacyjny schemat systemu rezerwacji zgodny z wymaganiami projektu: użytkownicy i role, kategorie, usługi, pracownicy, relacja N:M pracowników z usługami, dostępność oraz rezerwacje.

Najprościej uruchomić instalację przez `setup.php`. Skrypt utworzy bazę, tabele i dane startowe.
